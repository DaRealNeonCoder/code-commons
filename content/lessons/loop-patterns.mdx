The previous lesson showed how `for` and `while` repeat code. This lesson focuses on the patterns you can reuse when the problem changes.

## Accumulate a result

Start with a neutral value, update it once per item, and use it after the loop:

```python
total = 0
for price in [3, 5, 2]:
    total += price
```

The starting value depends on the operation: `0` for a sum, `1` for a product, and an empty list for collecting results.

## Count and search

Counting is an accumulator whose update is conditional:

```python
count = 0
for word in words:
    if len(word) > 4:
        count += 1
```

For a search, keep a clear answer such as `found = False`, or return immediately from a function when the match is found. Use `break` when the surrounding code still needs to run after the loop.

## Validate input

Validation often means “keep asking while the value is not acceptable”:

```python
while True:
    answer = input()
    if answer in ("yes", "no"):
        break
```

In a puzzle, the input is usually already valid. The pattern still matters because real programs must decide what to do with empty, out-of-range, or incorrectly formatted data.

> Before a loop, decide what the result should be before processing any items. That choice usually tells you the correct initial accumulator.
