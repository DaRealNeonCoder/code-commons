# The same point, four meanings

A vertex starts in **model space**, where a cube is centered around the origin.
The CPU's object transform places it in **world space**. The camera's view
transform expresses the world relative to the camera. Projection maps that
view-space point into clip space, where WebGL clips and rasterizes it.

The vertex shader performs the standard chain:

```glsl
vec4 world = u_model * vec4(a_position, 1.0);
gl_Position = u_projection * u_view * world;
```

Matrix order matters because matrix multiplication is not commutative. Scaling
then translating is different from translating then scaling. The engine owns
the model, view, and projection matrices; the lesson is about reading their
meaning and changing the CPU transforms deliberately.
