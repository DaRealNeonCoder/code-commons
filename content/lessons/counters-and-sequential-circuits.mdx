A counter is a register with a feedback rule: on each clock edge, it stores the old value plus one. With a fixed width, it eventually wraps around.

```text
next count = current count + 1
```

The register provides memory; the adder provides computation; the clock decides when the new result is captured. This is the first time in the course that those pieces act as one sequential circuit.
