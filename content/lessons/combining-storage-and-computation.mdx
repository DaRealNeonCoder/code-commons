Computation and storage have different jobs:

- The **ALU** calculates a candidate result.
- A **MUX** chooses which candidate should be written back.
- A **register** holds the chosen value.
- A **clock edge** makes the update happen.

That pattern is a tiny datapath. Real processors repeat it with wider values and more operations.
