# React demos

This lesson is a small integration test for interactive lesson examples. The component below runs inside a restricted preview frame, so clicking it changes the demo without changing the lesson page.

<ReactDemo
  title="A stateful counter"
  code={`function Demo() {
  const [count, setCount] = React.useState(0);
  return React.createElement(
    "button",
    { onClick: () => setCount(count + 1) },
    "Clicked " + count + " times"
  );
}`}
/>
