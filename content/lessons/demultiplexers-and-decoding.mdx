A **demultiplexer**, or demux, takes one data input and routes it to one selected output. For a 1-to-2 demux:

```text
Y0 = D AND NOT S
Y1 = D AND S
```

Only one output can receive the active data bit for a valid select value. If `D` is zero, both outputs are zero.

The [one-to-two demultiplexer puzzle](/circuits/one-to-two-demultiplexer?lesson=demultiplexers-and-decoding&course=intro-to-computer-engineering-part-2) checks both outputs. A circuit that turns both LEDs on at once has not routed the data correctly.
