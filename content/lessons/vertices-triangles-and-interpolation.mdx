# A triangle is the programmable 3D primitive

The engine's programmable geometry uses flat arrays:

```js
engine.geometry.from({
  positions: [-1, -1, 0, 1, -1, 0, 0, 1, 0],
  normals: [0, 0, 1, 0, 0, 1, 0, 0, 1],
  uvs: [0, 0, 1, 0, 0.5, 1],
  indices: [0, 1, 2],
});
```

The current runner binds exactly `a_position`, `a_normal`, and `a_uv`, and
renders indexed triangles. A vertex shader can write `gl_Position` and pass
values through `varying` variables. During rasterization those values are
interpolated across the triangle before the fragment shader reads them.

## Checkpoint

The [triangle interpolation puzzle](/shaders/graphics-triangle-interpolation)
requires a triangle whose three corners have distinct colors. Its center must
be the average of the three corner colors. Change one vertex color to predict
the center before rendering it.

The fragment-only path is still the right tool for a full-screen mathematical
image. Use programmable geometry when the vertices themselves carry useful
structure or when the CPU needs to control multiple objects.
