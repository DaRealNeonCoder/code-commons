So far, every output has been determined by the inputs visible **right now**. That is combinational logic. If the same inputs always produce the same output, the circuit has no memory of what happened earlier.

A circuit with **state** can remember a value. A button press might change a stored bit, and the stored bit can remain `1` after the button is released. Clocks, latches, flip-flops, registers, and memory build on this idea. We will only use the distinction here; a follow-up course can explore the hardware in detail.

| Kind of circuit | Output depends on | Example |
| --- | --- | --- |
| Combinational | current inputs | AND gate |
| Stateful | current inputs and stored state | a one-bit memory cell |
