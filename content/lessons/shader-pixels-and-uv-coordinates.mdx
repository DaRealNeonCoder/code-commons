# Pixels are the first geometry

In codeloop's **shader art** workflow you edit one fragment shader and see an
image immediately. The engine supplies a full-screen triangle, so you do not
need a scene, mesh, camera, or CPU program yet. Your `main` function runs once
for each pixel and writes `fragColor`.

`gl_FragCoord.xy` is the pixel's position in the drawing buffer. Divide by
`iResolution.xy` to get UV coordinates in the range `[0, 1]`:

```glsl
vec2 uv = gl_FragCoord.xy / iResolution.xy;
fragColor = vec4(uv.x, uv.y, 0.0, 1.0);
```

The bottom-left pixel has a small UV value and the top-right pixel has a large
one. This is a coordinate system you can inspect directly instead of treating
the canvas as a mysterious picture.

## Checkpoint

In the [UV gradient puzzle](/shaders/graphics-uv-gradient), render red from
left to right and blue from bottom to top. The checker samples a fixed image,
so the objective is precise: use the supplied resolution, keep alpha at `1.0`,
and do not animate it.

The fragment workflow also supplies `iTime`, `iTimeDelta`, `iFrame`, `iMouse`,
and `iCamera`. We will use those later; simple shader art never requires you
to learn the programmable 3D API.
