With `n` bits, there are `2^n` possible bit patterns. If we interpret every pattern as an unsigned number, the range is:

```text
0 through 2^n - 1
```

So 3 bits represent 8 patterns, from `000` (0) through `111` (7). Adding a fourth bit doubles the number of patterns and raises the largest value to 15.
