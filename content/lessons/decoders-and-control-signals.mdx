A **decoder** interprets an input pattern and activates one matching output. A 2-to-4 decoder has two input bits and four outputs:

| A | B | active output |
| ---: | ---: | --- |
| 0 | 0 | Y0 |
| 0 | 1 | Y1 |
| 1 | 0 | Y2 |
| 1 | 1 | Y3 |

The one-active-output pattern is called **one-hot**. A decoder can turn an address into a single memory-enable signal or turn instruction bits into control signals.
