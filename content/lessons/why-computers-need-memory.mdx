In Part 1, every circuit was **combinational**: change the inputs and the output changes according to the same rule. That is useful, but it cannot remember what happened a moment ago.

Memory gives a computer a past. A stored bit can represent “the user is logged in,” “the counter reached 7,” or “this instruction is waiting to run.” The important distinction is not that memory is mysterious; it is that the output can depend on both current inputs and a previously stored value.

> [!TIP]
> “What is the output now?” describes combinational logic. “What was stored earlier?” introduces state.
