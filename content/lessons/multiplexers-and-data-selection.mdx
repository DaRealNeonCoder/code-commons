A **multiplexer**, or MUX, chooses one input and forwards it to an output. A 2-to-1 MUX has `D0`, `D1`, and a select bit `S`:

```text
S = 0 → Y = D0
S = 1 → Y = D1
```

The select bit is control information. It does not become the output itself; it decides which data path is connected.
