A **feedback path** sends an output back around as an input. This sounds circular because it is: the circuit’s next result can depend on its previous result.

Feedback is the ingredient that combinational circuits were missing. A pair of gates can reinforce one stable condition, then switch to another when a control input changes. Real storage circuits are carefully designed so that feedback settles instead of changing forever.

The NAND-only puzzle editor in Part 1 focuses on acyclic circuits, so it cannot safely simulate a feedback loop yet. We can still reason about the idea with a timeline:

```text
control input → gate → output → feedback path → gate
                         ↑
                    previous value
```
