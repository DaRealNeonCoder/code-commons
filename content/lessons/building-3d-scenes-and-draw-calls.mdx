# A scene is a list of draw calls

`engine.scene.add` returns an object with `position`, `rotation`, `scale`,
`geometry`, and `material`. Each visible object becomes one indexed triangle
draw. Keep object creation in `setup`; mutate transforms in `update`.

```js
const left = engine.scene.add({
  geometry: engine.geometry.cube(),
  material: engine.material({ uniforms: { u_color: [1, 0.25, 0.25] } }),
  position: [-1.2, 0, 0],
});
const right = engine.scene.add({
  geometry: engine.geometry.plane(),
  material: engine.material({ uniforms: { u_color: [0.25, 1, 0.6] } }),
  position: [1.2, 0, 0],
});
```

Use `scene.remove(object)` and `scene.clear()` for lifecycle experiments. A
scene is not a game: this course stops at rendering, transforms, and input.

## Project

Open [Programmable 3D Gallery](/shaders/programmable-3d-gallery). Render a
cube, plane, and custom triangle with three materials. The acceptance target
is three visible objects, three distinct colors, and independent rotation of
the cube and triangle. Do not duplicate geometry data when a built-in helper
or one shared geometry object is enough.
