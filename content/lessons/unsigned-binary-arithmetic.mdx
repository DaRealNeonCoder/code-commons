Unsigned binary arithmetic follows the same column-by-column pattern as decimal arithmetic. The difference is that each column has only two digits, so `1 + 1` produces a zero in that column and a carry of one into the next.

For example:

```text
   0111   (7)
+  0011   (3)
--------
   1010   (10)
```

The carry is not an annoyance added after the fact. It is one of the outputs the hardware must produce so the next column can use it.
