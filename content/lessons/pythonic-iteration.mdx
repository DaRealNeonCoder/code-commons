The Intro course taught the loop mechanics. Pythonic code makes the data flow explicit without hiding important decisions.

## Transform, filter, and pair

```python
squares = [n * n for n in numbers]
large = [n for n in numbers if n > 10]
paired = list(zip(names, scores))
```

Use a comprehension when it is one readable transformation. Use a normal loop when the body has multiple actions, error handling, or nested decisions. A shorter line is not automatically clearer.

Unpacking names the parts of a structure:

```python
first, *middle, last = values
for index, value in enumerate(values, start=1):
    print(index, value)
```

## Sort by a computed key

`sorted(records, key=lambda record: record["score"], reverse=True)` separates ordering from the record itself. For a named rule, a normal function is often easier to test than a long lambda.

## Compose standard-library iterators

The `itertools` module provides lazy building blocks such as `chain`, `islice`, `repeat`, and `groupby`. “Lazy” means values are produced as requested rather than all stored at once. Preserve the input ordering assumptions that a tool such as `groupby` requires.
