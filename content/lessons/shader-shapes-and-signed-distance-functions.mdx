# A circle without a mesh

Center the pixel coordinate and correct for aspect ratio:

```glsl
vec2 p = (2.0 * gl_FragCoord.xy - iResolution.xy) / iResolution.y;
```

The signed distance to a circle of radius `r` is `length(p) - r`. Negative
values are inside, positive values are outside, and zero is the boundary. A
hard comparison works, but a narrow `smoothstep` range gives an antialiased
edge:

```glsl
float d = length(p) - 0.5;
float inside = 1.0 - smoothstep(-0.01, 0.01, d);
fragColor = vec4(mix(vec3(0.02), vec3(0.2, 0.75, 1.0), inside), 1.0);
```

This is a shader-art superpower: the image is generated from a formula, not
from CPU-created vertices. The same idea extends to boxes, capsules, rings,
and eventually 3D scenes.

circle with a dark background and a cyan interior. The checker evaluates the
rendered pixels, including the boundary. Match the radius before adding glow.

> to reuse the same geometry for outlines, glow, shadows, and combinations.
