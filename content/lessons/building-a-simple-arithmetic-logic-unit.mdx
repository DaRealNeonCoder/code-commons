An **arithmetic logic unit**, or ALU, is a combinational component that performs an operation selected by control bits. A deliberately small ALU can choose between:

```text
OP = 0 → A AND B
OP = 1 → A + B + CIN
```

The ALU needs a result output and a carry output. The result multiplexer chooses which operation’s result becomes visible; a small control rule keeps carry at zero during the AND operation.
