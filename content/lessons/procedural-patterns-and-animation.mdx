# Make one shape become many

Procedural patterns come from transforming coordinates before evaluating a
shape. `fract` repeats a tile, `floor` identifies a cell, and `mod` gives
repeating phases. A centered tile coordinate is often useful:

```glsl
vec2 cell = fract(uv * 6.0) - 0.5;
float d = length(cell) - 0.22;
float glow = 1.0 - smoothstep(0.0, 0.04, abs(d));
```

For motion, offset the coordinate with `iTime` rather than moving every object
on the CPU. Rotate a point with a 2D matrix, then feed it into the same SDF.
This is still the immediate fragment workflow: one `main`, one image, no
engine setup.

## Checkpoint

The [grid pattern puzzle](/shaders/graphics-grid-pattern) requires a centered
five-by-five repetition. Match cell count and spacing at time zero. Then try
replacing the circle with a box or rotating each cell; the target checker is
deliberately deterministic so visual experimentation does not hide mistakes.
