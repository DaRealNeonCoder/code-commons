The Intro language-model lesson counted adjacent pairs. A recurrent neural network instead carries a learned hidden state from one time step to the next:

```text
hₜ = tanh(Wₓxₜ + Wₕhₜ₋₁ + b)
```

The same parameters are reused at every position, so a sequence can have variable length. The hidden state is a compressed summary, not an unlimited memory.

## Why plain RNNs struggle

During backpropagation through time, gradients are repeatedly multiplied by recurrent Jacobians. Values smaller than one can vanish; values larger than one can explode. A long-range clue may therefore be forgotten or become numerically unstable. Truncated backpropagation through time limits the number of steps used for the update, trading memory for an approximation.

## LSTM gates make memory explicit

An LSTM separates a cell state from the exposed hidden state and uses gates:

```text
forget gate:  fₜ = sigmoid(...)
input gate:   iₜ = sigmoid(...)
candidate:    c̃ₜ = tanh(...)
cell state:   cₜ = fₜ × cₜ₋₁ + iₜ × c̃ₜ
output gate:  oₜ = sigmoid(...)
hidden:       hₜ = oₜ × tanh(cₜ)
```

The cell path gives information a more direct route through time. Gates can retain, overwrite, or reveal information. LSTMs reduce—but do not eliminate—the cost of sequential computation and long contexts.

## When recurrence is the wrong tool

RNNs and LSTMs process positions sequentially, which limits parallelism during training. They can be a good fit for streaming or small stateful tasks, but long-context language and vision systems often use attention to connect positions directly. The next lessons explain that transition rather than treating Transformers as magic replacements.

> [!TIP]
> Draw the state at every time step. If you cannot say what is carried forward, you cannot diagnose whether the model forgot, overwritten, or never received the relevant signal.
