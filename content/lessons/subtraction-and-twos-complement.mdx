Computer designers often avoid building a completely separate subtraction machine. In a fixed width, two’s complement turns subtraction into addition:

```text
A - B = A + (invert B + 1)
```

For 4 bits, the two’s complement of `0011` is:

1. invert: `1100`
2. add one: `1101`

Interpreted as a signed 4-bit number, `1101` represents `-3`. The bit pattern depends on the chosen width, so always write down the width before converting.
