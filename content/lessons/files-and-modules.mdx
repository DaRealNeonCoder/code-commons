Until now, input came from the puzzle's input box. Files let a program work with data that lasts after the program stops. Modules let you organize useful code and reuse tools from Python's standard library.

## Read and write with `with`

Use a `with` block so Python closes the file even if the block finishes through an error:

```python
with open("notes.txt", "r") as file:
    text = file.read()

with open("summary.txt", "w") as file:
    file.write("finished\n")
```

The mode matters: `"r"` reads, `"w"` replaces or creates a file, and `"a"` appends. A real program should choose paths carefully and handle a missing file instead of assuming it exists.

For line-oriented data, iterate over the file or use `read().splitlines()`. Strip only what you mean to strip; whitespace may be part of the data.

## Import a module

Python's standard library contains modules such as `math`, `statistics`, and `random`:

```python
import math

print(math.sqrt(25))
```

`import math` gives you a name `math`; `math.sqrt` looks up the function inside the module. Importing a module does not make every name global by magic. Prefer clear imports while you are learning.
