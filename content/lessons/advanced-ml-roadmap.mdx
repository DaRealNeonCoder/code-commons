This course assumes you have completed [Intro to AI & Machine Learning](/courses/intro-to-ai-machine-learning). You should already be able to read Python, manipulate vectors and matrices, differentiate a loss, run gradient descent, explain train/test leakage, and implement a small neural network. We will use those ideas rather than reteach them.

The goal here is not to collect fashionable model names. It is to learn the decisions that make a model more capable **and** more trustworthy: choosing an optimizer, controlling generalization, designing representations, selecting an architecture, measuring a real experiment, and serving a useful result.

## The course progression

| Stage | Question | Main build |
| --- | --- | --- |
| Optimization | How can training become faster and steadier? | momentum and Adam updates |
| Generalization | Why does a larger model fail on new data? | weight decay, dropout, early stopping |
| Architectures | How should a model use space or depth? | CNN blocks and residual connections |
| Representations | What useful structure can a model discover? | embeddings, contrastive learning, autoencoders |
| Sequences | How should a model use order and context? | RNNs, LSTMs, attention, Transformers |
| Systems | How do we train and use it responsibly? | token pipeline, efficient training, deployment, RAG |

Each lesson has a small from-scratch implementation. The puzzles use plain Python lists and deterministic inputs so you can inspect the algorithm without installing a framework. In a real project, the same ideas map to PyTorch or another tensor library.

## A repeatable experiment loop

Write down the question before changing code:

1. Make a hypothesis, such as “a cosine-decay schedule will reduce late-epoch oscillation.”
2. Fix the data split and random seed.
3. Change one important variable.
4. Record training loss, validation loss, runtime, and the final setting.
5. Keep the best checkpoint by a preselected validation rule.

An experiment is not “the last run looked good.” It is a comparison whose conditions are known well enough to repeat.
