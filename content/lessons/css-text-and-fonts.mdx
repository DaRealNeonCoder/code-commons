Text is most of what people read on the web, so the text properties are some of the most useful in CSS.

```css
p {
  font-family: Georgia, serif;
  font-size: 18px;
  line-height: 1.6;
  text-align: left;
}
```

## Font family

`font-family` picks the typeface. List a few choices in order, and end with a generic family. The browser uses the first one it has:

```css
body {
  font-family: "Helvetica Neue", Arial, sans-serif;
}
```

Generic families are `serif` (with little feet on the letters), `sans-serif` (without), and `monospace` (every letter the same width). Quote any font name that has a space in it.

## Size and weight

- `font-size` sets how big the letters are. `16px` is a common body size.
- `font-weight` sets how thick they are. `normal` is 400, `bold` is 700.

Headings are often bigger than body text. Use a size that matches the job: a page title might be `48px`, and body text `18px`.

## Spacing lines

`line-height` sets the distance between lines of text. A unitless value such as `1.6` means "1.6 times the font size", which keeps the spacing in proportion when the size changes. Generous line height makes long paragraphs easier to read.

## Alignment

`text-align` lines the text up: `left`, `center`, `right`, or `justify`. Left alignment is the easiest to read for paragraphs, so use centering for short things like titles.

> [!TIP]
> Units matter. `px` is a fixed number of screen pixels. `em` and `rem` scale with the font size, which helps people who set a larger text size in their browser. This course uses `px` for clarity, and you can explore the others later.
