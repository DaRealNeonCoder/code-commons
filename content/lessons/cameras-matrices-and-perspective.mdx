# A camera is a transform, not a magical viewport

The engine camera exposes `position`, `target`, `fov`, `near`, `far`, and
`lookAt(x, y, z)`. It constructs a view matrix from the camera pose and a
perspective projection from field of view, aspect ratio, and clipping planes.
Perspective makes distant objects appear smaller; orthographic projection is
not currently a runner option.

Pointer input is normalized. In the CPU update callback, `input.x` and
`input.y` run from zero to one and `input.down` reports the pointer button. A
simple orbit controller can convert two angles into a camera position:

```js
const radius = 4.5;
engine.camera.position.set(
  Math.sin(yaw) * radius,
  Math.sin(pitch) * radius,
  Math.cos(yaw) * radius,
);
engine.camera.lookAt(0, 0, 0);
```

## Checkpoint

The [perspective puzzle](/shaders/graphics-perspective) contains two equal
planes at different depths. Match the camera at `(0, 0, 5)`, target the origin,
and use a 45° field of view. Then add pointer orbiting as an extension. The
static target keeps camera math objectively checkable before interaction.
