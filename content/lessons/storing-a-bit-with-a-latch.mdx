An SR latch exposes set and reset controls directly. A data latch is easier to use as a storage component: give it a data bit `D` and a write or enable signal.

```text
if WRITE is active: Q becomes D
otherwise:          Q keeps its old value
```

That rule is the beginning of a memory interface. A computer can put a value on a shared data path, activate a particular write control, and leave every other storage location alone.

    <p>Stored Q: <strong>{q ? '1' : '0'}</strong></p>
    <small>Apply with WRITE off and Q holds its previous value.</small>
  </div>;
