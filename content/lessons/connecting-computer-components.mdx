A small computer is not one giant circuit. It is a conversation between components:

```text
registers → buses → ALU → MUX → registers
     ↑         ↑      ↑      ↑
   clock   control signals  decoder
```

The details become more advanced later, but the roles are already familiar. Registers remember. Buses carry bits. The ALU computes. Multiplexers select. Decoders create control signals. A clock keeps updates coordinated.
