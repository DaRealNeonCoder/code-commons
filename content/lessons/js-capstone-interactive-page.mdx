You now know the three languages. This capstone uses all of them to build something real: a click counter with a Plus button and a Reset button.

## Plan first

Before you type any code, write down what the page needs to do:

1. It shows a number, starting at 0.
2. Clicking **+1** adds one.
3. Clicking **Reset** sets the number back to 0.
4. The number is big and easy to read.

Each line of that plan maps to one part of the code. The HTML provides the elements, the CSS makes the number large, and the JavaScript handles the clicks.

## The structure

```html
<h1>Click Counter</h1>
<p id="count">0</p>
<button id="plus">+1</button>
<button id="reset">Reset</button>
```

Every element that JavaScript needs has an `id`. That's the link between the two languages.

## The style

```css
#count {
  font-size: 48px;
}
```

## The behavior

The number needs to live in JavaScript so it can change. Keep it in a variable, change the variable, and then update the page:

```javascript
const count = document.querySelector("#count");
let total = 0;

document.querySelector("#plus").addEventListener("click", () => {
  total = total + 1;
  count.textContent = total;
});

document.querySelector("#reset").addEventListener("click", () => {
  total = 0;
  count.textContent = total;
});
```

Notice the pattern: **change the data, then show the data**. The page never holds the real number. The variable does, and the page displays it.

## Checking your work

Test each part of the plan in order, the way a visitor would:

1. Load the page. Does it show 0?
2. Click **+1** once. Does it show 1?
3. Click **+1** again. Does it show 2?
4. Click **Reset**. Does it show 0?

The checks in this puzzle do exactly that, one step at a time.

> [!TIP]
> When something doesn't work, check the steps in order. If the number doesn't change, the problem is in the click handler. If the number changes but looks wrong, the problem is in the CSS.

## Where to go next

You now know how to build a page from structure, style, and behavior. The next steps are to:

- Build a page from scratch, with no starter code, and check it in a browser.
- Learn the developer tools (press F12) to inspect the page and see errors.
- Explore how real sites are organized into several files and pages.

## Your puzzle

Make the counter work. In the CSS tab, make the number `#count` 48 pixels in font size. In the JavaScript tab, make **+1** add one to the number and **Reset** set it back to 0. The checks click +1, then +1 again, then Reset, and read the number each time.
