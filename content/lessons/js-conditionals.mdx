A program is useful because it can choose. A **conditional** runs one block of code when a condition is `true` and another when it is `false`.

## if and else

```javascript
const isRaining = true;
let plan;

if (isRaining) {
  plan = "stay in";
} else {
  plan = "go out";
}
```

The condition goes in parentheses after `if`. The code to run goes in curly braces. `else` handles everything else. Because `isRaining` is `true`, `plan` becomes `"stay in"`.

## else if

When there are more than two choices, chain them with `else if`. The first condition that is `true` wins, and the rest are skipped:

```javascript
const temperature = 18;
let weather;

if (temperature < 10) {
  weather = "cold";
} else if (temperature < 20) {
  weather = "mild";
} else {
  weather = "warm";
}
```

Order matters. Put the most specific condition first, or an earlier broad check will catch everything.

## The ternary operator

A ternary chooses between two values in a single expression. It has the form `condition ? valueIfTrue : valueIfFalse`:

```javascript
const umbrella = isRaining ? "take it" : "leave it";
```

Use it for simple choices that fit on one line. Switch back to `if` when the choice is complicated.

## Truthy and falsy

Conditions don't need to be booleans. JavaScript treats some values as `false` in an `if`: `0`, `""` (empty text), `null`, `undefined`, and `NaN`. Almost everything else is `true`.

```javascript
const name = "";
if (name) {
  // skipped, because an empty string is falsy
}
```

> [!TIP]
> Write conditions that read like a sentence. `if (age >= 18)` is clearer than `if (!(age < 18))`, even though they mean the same thing.
