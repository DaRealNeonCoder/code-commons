A **truth table** lists every possible input combination and the output produced by a rule. Two inputs have four combinations, so a two-input table has four rows. Three inputs have eight combinations.

For a circuit such as `Q = (A AND B) OR C`, work from the inside out. First calculate `A AND B`, then combine that temporary result with `C` using OR. Naming intermediate results prevents a long expression from becoming a guessing game.

<ReactDemo
  title="Trace one row at a time"

  const rows = [[0, 0, 0], [0, 1, 1], [1, 0, 0], [1, 1, 1]];

  const andResult = a && b;
  const output = Boolean(andResult || c);

Truth tables are also a debugging tool. If your circuit is wrong, find the first row where its output disagrees with the specification. Then trace the gate feeding that output instead of staring at the whole diagram.
