A linked list stores a sequence as separate **nodes**. Each node contains a value and a reference to the next node. The nodes do not have to sit beside one another in memory; following `next` links gives the order.

This lesson assumes Intro to Python familiarity with classes, variables, loops, and `None`. The new idea is to treat an object reference as an arrow that can be rewired.

```python
class Node:
    def __init__(self, value, next_node=None):
        self.value = value
        self.next = next_node


tail = Node(30)
middle = Node(20, tail)
head = Node(10, middle)
```

This represents `10 -> 20 -> 30 -> None`. The `head` reference is the entry point. Unlike an array, a linked list cannot jump to “index 2” without following two links, so indexing is O(n). Finding a value is also O(n). If we already have the node or the position where a change belongs, changing a link can be O(1).

## Reversing means changing arrows

To reverse `A -> B -> C -> None`, do not overwrite `B`'s link before saving where it used to point. Keep three references:

```python
previous = None
current = head
while current is not None:
    following = current.next
    current.next = previous
    previous = current
    current = following
head = previous
```

At the end of each loop, `previous` is the head of a reversed prefix and `current` is the first node not yet processed. `following` protects the rest of the original list while the arrow is rewired. This is a pointer operation, not a copy of every value.

## Invariants and edge cases

During reversal, the nodes in the reversed prefix point backward in their final order, while `current` still reaches every unvisited node in the original order. The two parts are separate: there is no accidental cycle between them. When `current` becomes `None`, every original link has been handled and `previous` is the new head.

An empty list has `head = None` and reverses to `None`. A one-node list points to `None` before and after. Always save the next reference before changing a link; otherwise the rest of the list becomes unreachable. A traversal should stop at `None`, not assume a fixed number of nodes.

Reversal takes O(n) time and O(1) extra references. Building nodes from an input sequence takes O(n) time, but the rewiring itself does not need a second list.
