Python is a general-purpose programming language created by Guido van Rossum and first released in 1991. It is popular because its code reads almost like plain English, so you spend less time wrestling with syntax and more time solving problems. People use it for websites, automation, data analysis, games, and AI.

A Python program is just a text file full of instructions. Python reads them from top to bottom, one line at a time, and does what each line says.

## Your first program

```python
print("Hello, World!")
```

Output:

```
Hello, World!
```

Here is what each part does:

- `print` is a built-in **function**. It displays something on the screen.
- The parentheses `( )` hold what you want to print. This is called the **argument**.
- `"Hello, World!"` is a **string**: text wrapped in quotes. Single quotes (`'hi'`) and double quotes (`"hi"`) both work.

> [!WARNING]
> Python is case-sensitive. `Print("hi")` raises an error, but `print("hi")` works.

## Printing more than one thing

Give `print()` several arguments separated by commas and it prints them all, with a space between each:

```python
print("Python", "is", "fun")
```

Output:

```
Python is fun
```

Two optional arguments let you change how `print()` behaves:

| Argument | What it controls | Default |
| --- | --- | --- |
| `sep` | What goes *between* items | a single space |
| `end` | What goes *after* the last item | a new line |

```python
print("2025", "06", "01", sep="-")
print("Loading", end="...")
print("done")
```

Output:

```
2025-06-01
Loading...done
```

Every `print()` normally starts a new line. Setting `end=""` or `end="..."` keeps the next print on the same line.

Numbers don't need quotes, and Python will do the math before printing:

```python
print(2 + 3)
print("2 + 3")
```

Output:

```
5
2 + 3
```

The first line is a calculation. The second is just text, so Python prints it exactly as written.

## Comments

Anything after a `#` is a **comment**. Python ignores it, so you can leave notes for yourself and other people.

```python
# This line is ignored by Python
print("Comments are useful")  # You can also put them at the end of a line
```

Good comments explain *why* you did something, not just *what* the code does.

> [!TIP]
> Comments are also handy for switching a line off while you debug. Put a `#` in front of it and Python skips it.

<Details title="Why is the first program always 'Hello, World!'?">
It's a tradition that goes back to a 1970s programming book. Printing a greeting is the smallest program that proves your setup works and shows you how output happens.
</Details>
