Welcome! A program is a set of instructions for a computer. In this lesson,
you will write one tiny instruction and see the computer follow it.

Your first Python program needs just one line. `print()` tells Python to show
something in the output:

```python
print("Hello, World!")
```

It prints:

```
Hello, World!
```

The words inside the quotes are the message. Change them to anything you like
and Python will print your version instead:

```python
print("I am learning to code!")
```

Here is what each part means:

- `print` is the name of a built-in Python instruction.
- `(` and `)` mark the value we are giving to that instruction.
- The quotes mark the message as text. Text is also called a **string**.

Python is particular about spelling and punctuation, so keep `print` lowercase
and keep the parentheses and quotes. If you make a typo, that is normal: read
the error message, compare your line with the example, and try again.

**Ready to make it yours?** The first puzzle gives your program a name and asks
you to print a greeting. The starter code reads the name for you; you only need
to write the `print()` line. You can look up the examples below whenever you
need them. There is no penalty for experimenting.

## Printing more than one thing

Give `print()` several values separated by commas and it prints them all, with
a space between each:

```python
print("Python", "is", "fun")
```

Output:

```
Python is fun
```

Two optional arguments let you change how `print()` behaves. You can try `sep`
in the first puzzle:

| Argument | What it controls | Default |
| --- | --- | --- |
| `sep` | What goes *between* items | a single space |
| `end` | What goes *after* the last item | a new line |

```python
print("2025", "06", "01", sep="-")
print("Loading", end="...")
print("done")
```

Output:

```
2025-06-01
Loading...done
```

Every `print()` normally starts a new line. Setting `end=""` or `end="..."` keeps the next print on the same line.

Numbers do not need quotes, and Python will do the math before printing:

```python
print(2 + 3)
print("2 + 3")
```

Output:

```
5
2 + 3
```

The first line is a calculation. The second is just text, so Python prints it
exactly as written. Quotes are what tell Python not to calculate the contents.

## Comments

Anything after a `#` is a **comment**. Python ignores it, so you can leave notes
for yourself and other people. Comments do not change the program's output.

```python
# This line is ignored by Python
print("Comments are useful")  # You can also put them at the end of a line
```

Good comments explain *why* you did something, not just *what* the code does.

> [!TIP]
> Comments are also handy for switching a line off while you debug. Put a `#` in front of it and Python skips it.

## A note about the puzzles

In the first few puzzles, the starter code already contains lines like
`name = input()`. That line reads the text from the **Input** box and saves it
in a variable called `name`, so you do not have to learn `input()` yet. For
now, just use the variable it creates:

```python
name = input()       # the puzzle provides this line
print("Hello", name) # your code uses the name
```

The first puzzle asks you to add a comma and a space between the greeting and
the name. The second puzzle builds on it by printing words on one line and then
on separate lines. Take them one small step at a time.
