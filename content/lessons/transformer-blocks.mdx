Attention lets tokens exchange information. A Transformer block adds two other ideas: a position-wise feed-forward network that transforms each token independently, and residual/normalization paths that keep deep stacks trainable.

## A common block shape

A simplified pre-normalization decoder block is:

```text
x = x + self_attention(layer_norm(x))
x = x + feed_forward(layer_norm(x))
```

The feed-forward network expands the hidden width, applies a nonlinearity such as GELU, and projects back down. Attention mixes information across positions; the MLP changes the features at each position. They solve different problems.

## Position is information

Self-attention by itself does not know whether a token came first or last. Add positional information to token embeddings before attention, either with fixed sine/cosine functions or learned position embeddings. Relative-position methods instead encode distances or directional relationships in the attention calculation.

## Normalization and residuals

Layer normalization standardizes features within one token representation using a learned scale and shift. Residual paths preserve the current representation and provide a direct gradient route. Pre-normalization often makes deep optimization more stable; the exact placement is an architectural choice to test rather than a slogan to memorize.

> [!TIP]
> A Transformer is an architecture assembled from familiar operations: matrix projections, softmax attention, normalization, nonlinear layers, and residual addition. Understanding the data flow is more valuable than memorizing the name.
