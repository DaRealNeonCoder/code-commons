A **stack** and a **queue** are defined by the order in which items leave. A stack is **LIFO**: last in, first out. A queue is **FIFO**: first in, first out. Their simple rules make them useful for different jobs.

This lesson assumes Intro to Python familiarity with lists, function calls, and importing a standard-library type. We will focus on the ordering rules and the invariants that make each operation safe.

```python
stack = []
stack.append("page A")
stack.append("page B")
last_page = stack.pop()       # page B

from collections import deque
queue = deque(["task A"])
queue.append("task B")
first_task = queue.popleft()  # task A
```

Appending and popping at the end of a Python list are usually O(1). Removing index 0 from a list is O(n), because all remaining items shift left. `deque` supports both ends efficiently. A circular buffer gives a queue the same idea using a fixed array and three numbers.

## A queue in a circle

Keep an array `buffer`, a `head` index for the oldest item, a `tail` index for the next free slot, and `size`. After using a slot, advance with modular arithmetic:

```python
tail = (tail + 1) % capacity
head = (head + 1) % capacity
```

The queue invariant is `0 <= size <= capacity`. If `size == 0`, dequeue is empty. If `size == capacity`, enqueue is full. When neither boundary applies, enqueue writes at `tail` and increments size; dequeue reads at `head` and increments head. The indices can wrap around without moving any other item.

## Edge cases and cost

For a stack, popping an empty stack needs a defined result such as `empty` or an exception. For a queue, distinguish empty from full even when `head == tail`; `size` supplies that missing information. A capacity of one still needs to wrap correctly. A capacity of zero can never accept an item and should be rejected or reported as full before taking a modulo.

Push, pop, enqueue, and dequeue are O(1) when the structure has the right representation. A fixed circular buffer uses O(capacity) space and never shifts the stored items. The tradeoff is a fixed limit, unless the buffer itself is resized.
