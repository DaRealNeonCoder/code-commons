# **Neon Camera Cathedral**

This shader is built from repeated neon ribs, animated rings, and a glowing core. Its `point` coordinate is transformed by `iCamera`, so the new preview controls turn the flat pattern into an explorable space.

Try **Shift-dragging** or **middle-dragging** to pan, using the **mouse wheel** to zoom toward the cursor, and using **WASD** or the **arrow keys** to fly around. Press **0** to return to the center. Moving the mouse also bends the pulse in the core through `iMouse`.
