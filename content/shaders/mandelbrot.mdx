      vec2 point = (2.0 * gl_FragCoord.xy - iResolution.xy) / iResolution.y;
      vec2 c = point * 1.4 + vec2(-0.5, 0.0);
      vec2 z = vec2(0.0);

          if (dot(z, z) > 16.0) break;

              z.x * z.x - z.y * z.y,

# **Mandelbrot Set**

Each pixel becomes a complex number `c`. The loop repeatedly applies `z = z² + c`; points that escape become colored according to how many iterations they survived, while points inside the set remain black.

Try changing the zoom and offset in the `c` calculation, increasing the iteration limit, or designing a different color palette. The fixed loop keeps the shader compatible with WebGL fragment shaders.
