# **Checkerboard Challenge**

Write a fragment shader that renders the target image: an eight by eight
checkerboard with navy and orange squares. Use `gl_FragCoord` and
`iResolution` to turn each fragment into a board coordinate.

Use navy **RGB (20, 33, 61)** and orange **RGB (252, 163, 17)**, dividing each
channel by 255.0 for GLSL colors. The **bottom-left square is navy**; alternate
colors horizontally and vertically. Every square occupies one eighth of the
image width and height. Set alpha to 1.0.

Hint: `floor(uv * 8.0)` gives a square's integer coordinates. Use the parity of
their sum to choose a color.

The target is checked at a fixed **96 × 96** resolution. Your code is rendered
at time zero and compared with the reference image, so animation is not needed
for this puzzle.

Select **check solution** to compare your current code with the target. At
least **96%** of pixels must be within **8%** per color channel. The live
preview can stretch with the workspace; the checker always uses the square
reference size.
