  void main() {
      vec2 point = (2.0 * gl_FragCoord.xy - iResolution.xy) / iResolution.y;

      float angle = iTime * 1.2;
      vec2 orbitCenter = vec2(cos(angle), sin(angle)) * 0.55;
      float distanceToOrb = length(point - orbitCenter);

      float radius = 0.12 + 0.035 * sin(iTime * 3.0);
      float orb = 1.0 - smoothstep(radius, radius + 0.015, distanceToOrb);

# **Pulsing Orbit**

Sine and cosine convert the current time into a point moving around a circle. The shader measures the distance from each pixel to that moving point, then layers a sharp orb over a wider, softer glow.

Try changing the orbit radius, angular speed, or pulse frequency. You can also replace the circular path with an ellipse by scaling one component of `orbitCenter`.
