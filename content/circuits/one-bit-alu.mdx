Build this small ALU from NAND gates:

```text
OP = 0 → RESULT = A AND B, COUT = 0
OP = 1 → RESULT = A + B + CIN, COUT = carry
```

Use a multiplexer-style selection rule for `RESULT`. The checker covers all 16
input combinations.
