Apply `weight - rate * (gradient + decay * weight)`. `best_epoch` is the first 1-based position of the minimum validation loss.

For the curve label, return `overfit` when training loss decreases overall but validation loss reaches its minimum before the final epoch and then rises. Return `underfit` when both final losses are at least `0.8`; otherwise return `balanced`. The examples are deliberately small: explain the pattern before trusting a metric.
