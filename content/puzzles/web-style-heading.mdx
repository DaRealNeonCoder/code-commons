Write a CSS rule in the CSS tab that makes every `h1` on the page red.

A rule is a selector, then the property and its value in curly braces:

```css
h1 {
  color: red;
}
```

The check reads the color the browser actually calculates, so `red`, `#ff0000`, and `rgb(255, 0, 0)` all pass.

> [!TIP]
> Keep the existing comment or delete it. CSS ignores anything between `/*` and `*/`.
