Trees are usually drawn from the root, but a tree is just a set of nodes and the connections between them, so any node can be the root. Re-rooting a tree at a different node means looking at the same tree from that node's point of view: the chosen node becomes the root, its former parent becomes one of its children, that node's former parent becomes a child of it, and so on up to the old root.

For example, re-rooting

```text
        parent
       /      \
      x      sibling
```

at `x` gives

```text
      x
      |
    parent
      |
   sibling
```

Your task is to re-root a tree at a given node.

## Input

The first line is the tree in JSON, e.g. `{"label": "parent", "children": [{"label": "x"}, {"label": "sibling"}]}` (`children` may be left out for a leaf). The second line is the label of the new root.

## Output

Print the re-rooted tree in JSON. Every node is printed as `{"label": ..., "children": [...]}` with `children` always present (an empty list for a leaf) and the children of each node sorted by label; the starter code does this normalising for you, so your function may return its children in any order. Print `none` if there is no node with that label.
