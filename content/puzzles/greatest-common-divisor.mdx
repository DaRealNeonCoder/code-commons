Write a function `gcd(a, b)` that returns the greatest common divisor of two positive integers, the largest number that divides both of them evenly.

For example, `gcd(25, 15)` is `5`.

> [!TIP]
> Try Euclid's algorithm: `gcd(a, b)` equals `gcd(b, a % b)`, and `gcd(a, 0)` is `a`.

The starter code reads both numbers from one line.
