Score each document by the number of distinct query words it contains. Sort by decreasing score while preserving the original order for ties, then return at most `limit` document IDs.

This toy ranker makes retrieval behavior inspectable. A production RAG system should add semantic embeddings, metadata/access filters, reranking, source citations, and tests for unanswered questions.
