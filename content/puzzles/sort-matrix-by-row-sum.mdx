A matrix is stored as a list of rows. Write a function `sort_by_row_sum(matrix)` that returns the rows reordered so that their **sums** go from smallest to largest. The rows themselves are not changed.

If two rows have the same sum, keep them in their original relative order.

For example, the rows `[1, 2, 3]`, `[-2, 4, -5]`, `[1, -1, 1]` have sums `6`, `-3` and `1`, so the result is `[-2, 4, -5]`, `[1, -1, 1]`, `[1, 2, 3]`.

> [!TIP]
> Most languages let you pass a "key" function to the sort. Use one that computes a row's sum.

The starter code reads the number of rows, then one row per line, and prints one row per line. Rows may have different lengths.
