The starter code reads three words, one per line. Print them on a single line separated by ` | `, then print each word on its own line.

For the input `red`, `green`, `blue`, a correct solution prints:

```
red | green | blue
red
green
blue
```

> [!TIP]
> You'll need one `print()` that uses `sep`, followed by three plain `print()` calls.
