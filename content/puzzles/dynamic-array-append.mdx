Simulate a dynamic array that starts with capacity `0`. Before each append, if `length == capacity`, allocate a new backing array: capacity `1` for the first item, then double the old capacity. Count how many existing items are copied during every resize.

Return the values in order, the total number of copied items, and the capacity after each append. The input count `n` matches the number of values. This is a simulation of amortized append, not an invitation to use Python's list capacity internals.
