Write a function `has_close_elements(numbers, threshold)` that returns `True` if **any two different elements** of the list are closer to each other than `threshold`, and `False` otherwise. "Closer" means the absolute difference is strictly less than the threshold.

> [!TIP]
> Comparing every pair works fine. For a faster approach, think about what sorting the list first would let you skip.

The starter code reads the numbers on the first line and the threshold on the second.
