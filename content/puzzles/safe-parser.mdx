Implement `parse_record`:

1. Split once at `:`; if there is no separator, raise `InvalidRecord("expected name:amount")`.
2. Strip the name; if it is empty, raise `InvalidRecord("empty name")`.
3. Convert the amount with `float()`; if conversion raises `ValueError`, raise `InvalidRecord("invalid amount")`.
4. Reject negative amounts with `InvalidRecord("negative amount")`.
5. Return the stripped name and numeric amount.
