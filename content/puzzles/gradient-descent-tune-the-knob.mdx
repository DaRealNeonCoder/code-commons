Complete `gradient(w)` for the bowl `f(w) = (w - 4)²`, then use the update loop already provided.

The input is a starting point, a learning rate, and a number of steps. Print the final point and its bowl value, rounded to three decimal places.

Try changing the learning rate after the tests pass. A very small rate crawls. A rate above `1` can overshoot back and forth. The goal is not to memorize `0.5`; it is to learn how to tune the knob for a surface.

> [!TIP]
> The derivative of `(w - 4)²` is `2 × (w - 4)`. At `w = 4`, the slope is zero, so there is no reason to move.
