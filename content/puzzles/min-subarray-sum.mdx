A **subarray** is a non-empty run of consecutive elements from a list. Write a function `min_subarray_sum(numbers)` that returns the smallest possible sum of any subarray.

For example, in `[2, 3, 4, 1, 2, 4]` the answer is `1` (the single element `1`), and in `[-1, -2, -3]` it is `-6` (the whole list).

> [!TIP]
> Track the best (smallest) sum of a subarray *ending at the current position*. At each step, either extend it or start fresh from the current element. This is Kadane's algorithm, flipped to find a minimum.

The starter code reads one line of integers and prints the answer.
