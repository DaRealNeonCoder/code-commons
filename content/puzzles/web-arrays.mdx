The starter creates an array named `fruits` with two items. In the JavaScript tab:

1. Add `"cherry"` to the end of `fruits` with `push`.
2. Create `count`, holding the number of items in `fruits`.
3. Create `second`, holding the item at index 1.

The checks read the length, `count`, `second`, and the item at index 2, which should now be `"cherry"`.

> [!TIP]
> Index 1 is the second item, because counting starts at 0. `fruits.length` is the number of items, so the last index is always `length - 1`.
