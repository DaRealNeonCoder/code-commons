      let countdown = "";

      for (let i = 1; i <= 10; i++) {
        total = total + i;
      }

      let n = 3;
      while (n > 0) {
        countdown = countdown + n;
        if (n > 1) {
          countdown = countdown + ",";
        }
        n = n - 1;
      }

The starter creates two variables, `total` and `countdown`. Write two loops:

1. A `for` loop that goes from 1 to 10 and adds each number to `total`. The total should be `55`.
2. A `while` loop that starts at `n = 3`, adds each number to `countdown`, puts a comma after every number except the last, and counts down. The result should be `"3,2,1"`.

The checks read `total` and `countdown`.

> [!TIP]
> Make sure your `while` loop changes `n` on every round, or it never stops. For the comma, check whether `n` is greater than 1 before you add one.
