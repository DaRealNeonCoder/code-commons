Choose the next child during the **selection** phase of Monte Carlo Tree Search (MCTS).

## Input

The first line contains the number of children, `n`. Each of the next `n` lines contains two non-negative integers: `visits` and `wins` for one child, in child-index order. The final line contains the exploration constant `c` as a real number.

The parent visit count is defined to be the sum of all child visit counts. For a visited child, calculate its UCB1 score as:

```text
wins / visits + c * sqrt(ln(parent_visits) / visits)
```

An unvisited child (`visits == 0`) has an infinite score, so it is preferred to every visited child. If multiple children have the same highest score, choose the one with the smallest index. The test data keeps wins between zero and visits.

## Output

Print the zero-based index of the selected child. The exploration term rewards children that have been visited less often, while the wins term rewards children that have performed well.
