`make_counter` should keep its count in an enclosing variable and return an inner function that increments it with `nonlocal`.

`record_calls(log)` should return a decorator. The decorator should wrap the original function, append `function.__name__` to `log`, call the original with `*args` and `**kwargs`, and return its result. Use `@wraps` so the wrapper keeps the original metadata.
