A bank account starts with a balance of `0`. You are given a list of deposits (positive numbers) and withdrawals (negative numbers), applied in order.

Write a function `below_zero(operations)` that returns `True` if the balance **ever** falls below zero, and `False` otherwise. A balance of exactly zero does not count.

> [!TIP]
> You don't need to store every balance. Keep a running total and check it after each operation.

The starter code reads the operations from a single line of space-separated integers and prints `true` or `false`. For the input `1 2 -4 5`, a correct solution prints `true` (the balance goes `1, 3, -1, 4`).
