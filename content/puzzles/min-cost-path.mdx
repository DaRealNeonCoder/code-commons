You are given a grid of non-negative numbers, where each cell is the cost of stepping on it. Starting in the top-left corner, you must reach the bottom-right corner, moving only **right** or **down** one cell at a time.

Write a function `min_cost_path(grid)` that returns the smallest possible total cost of a path. Both the starting cell and the final cell are included in the total.

For example, in the grid below the best path is `1 -> 3 -> 1 -> 1 -> 1` with a cost of `7`.

```
1 3 1
1 5 1
4 2 1
```

> [!TIP]
> The cheapest way to reach a cell is its own cost plus the cheaper of the two cells you could have come from (above or left). Fill the grid row by row.

The starter code reads the grid size on the first line, then the rows.
