Use `normalized = value / sqrt(value * value + 1e-6)`, then `after_attention = value + attention_output * normalized`. The MLP residual is `after_attention + mlp_scale * max(0, after_attention)`.

This scalar exercise is not a replacement for tensor shapes. It isolates the order of operations in a block so the same structure is recognizable in a framework implementation.
