      <html lang="en">

      <body>

Add two elements to the page:

1. A link, `<a>`, with the text `MDN` and an `href` of `https://developer.mozilla.org`.
2. An image, `<img>`, with a `src` of `cat.jpg` and an `alt` of `A cat`.

The image file doesn't exist in this puzzle, so the preview shows the alt text where the picture would be. That's expected.

> [!TIP]
> The `img` element has no closing tag. Write it as `<img src="..." alt="...">`.
