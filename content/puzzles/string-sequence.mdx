Write a function `string_sequence(n)` that returns a **string** containing every number from `0` up to and including `n`, separated by single spaces.

For example, `string_sequence(5)` returns `"0 1 2 3 4 5"`, and `string_sequence(0)` returns `"0"`.

> [!TIP]
> Most languages have a "join" helper that glues a list of strings together with a separator, which avoids a trailing space.

The starter code reads `n` and prints the string.
