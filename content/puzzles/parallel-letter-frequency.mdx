Count the frequency of letters in texts using parallel computation.

Parallelism is about doing things in parallel that can also be done sequentially.
A common example is counting the frequency of letters.
Employ parallelism to calculate the total frequency of each letter in a list of texts.

## Input

The first line is the number of texts `n`. Each of the next `n` lines is one text.

## Output

Print every letter that occurs, as `letter count`, one per line sorted alphabetically. Letters are counted case-insensitively and printed in lower case; digits, punctuation and spaces are ignored. Print nothing if there are no letters. The result is the same however you split the work, so you are free to use threads or processes.
