Create an object called `book` with three properties:

- `title`, set to `"Dune"`.
- `pages`, set to `412`.
- `read`, set to `false`.

Then set `book.read` to `true`, because you finished the book.

The checks read the title, the pages, and `book.read`, which should now be `true`.

> [!TIP]
> Properties are separated by commas, and the whole object is wrapped in curly braces. Use a colon between each name and its value.
