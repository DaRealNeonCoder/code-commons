      <!DOCTYPE html>
      <html lang="en">
      <head>
        <meta charset="UTF-8">
        <title>Practice</title>
      </head>
      <body>
        <div id="alert" class="box">Saved!</div>
        <button id="toggle">Highlight</button>
      </body>
      </html>
    css: |
      .box {
        padding: 12px;
        border: 1px solid gray;
      }

      .highlight {
        background-color: yellow;
      }
    js: |
      const alertBox = document.querySelector("#alert");

      document.querySelector("#toggle").addEventListener("click", function () {
        alertBox.classList.add("highlight");
        alertBox.textContent = "Highlighted!";
      });

The **Highlight** button should change the box with the id `alert`:

1. When `#toggle` is clicked, add the class `highlight` to `#alert` with `classList.add`.
2. In the same handler, change the text of `#alert` to `Highlighted!`.

The starter CSS already has a `.highlight` class with a yellow background. Your JavaScript only needs to add the class, and the browser does the rest.

The checks click the button first, then look at what changed: the text, whether the class is there, and the calculated background color.

> [!TIP]
> `classList.add` adds a class without removing the others. `classList.toggle` switches the class on and off with each click, which is useful for a button that turns something on and off.
