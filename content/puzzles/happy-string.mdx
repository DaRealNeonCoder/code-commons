A string is **happy** if it has at least 3 characters and every group of 3 consecutive characters are all different from each other.

Write a function `is_happy(s)` that returns `True` for a happy string and `False` otherwise. For example, `"abcd"` is happy, `"aabb"` is not (the first three letters repeat `a`), and `"aba"` is not either (the first and third letters match).

The starter code reads one string and prints `true` or `false`.
