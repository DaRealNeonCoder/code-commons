Build a table that shows scores:

- A header row with two `<th>` cells: `Name` and `Score`.
- A row for `Ada` with the score `95`.
- A row for `Grace` with the score `98`.

The checks count the rows and the header cells, and read the first name and the first score.

> [!TIP]
> Each row is a `<tr>`. Each cell inside it is a `<th>` for a heading or a `<td>` for a value.
