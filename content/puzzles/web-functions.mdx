Write two functions in the JavaScript tab:

1. A regular function named `double` that takes one parameter, `n`, and returns `n * 2`.
2. An arrow function named `greet` that takes one parameter, `name`, and returns `"Hello, "` followed by the name and an exclamation mark.

The checks call both: `double(21)` should be `42`, and `greet("Ada")` should be `"Hello, Ada!"`.

> [!TIP]
> Use `return` to send the result back. A function without `return` gives back `undefined`, which the check will report as a mismatch.
