Write a function `primes_below(n)` that returns a list of all prime numbers **strictly less than** `n`, in ascending order. For example, `primes_below(11)` returns `[2, 3, 5, 7]`.

> [!TIP]
> Testing each number separately works for small `n`. For large `n`, look up the *Sieve of Eratosthenes*, which crosses off multiples of each prime instead.

The starter code reads `n` (at least 3) and prints the primes separated by spaces.
