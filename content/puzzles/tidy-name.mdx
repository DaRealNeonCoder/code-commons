The starter code reads a messy name that might have extra spaces at the start or end and strange capitalization. Print the cleaned-up version: no surrounding spaces, and each word capitalized.

For the input `  aDA loVElace  `, a correct solution prints `Ada Lovelace`.

> [!TIP]
> String methods can be chained: `text.method_one().method_two()`.
