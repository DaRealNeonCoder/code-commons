A tree is a connected structure of labelled nodes in which every node except the root has exactly one parent. Because there is only one route between any two nodes, you can always find the path from one node to another by walking up towards the root and down again, regardless of which node is the root.

Your task is to find the path between two nodes of a tree.

## Input

The first line is the tree in JSON, e.g. `{"label": "parent", "children": [{"label": "x"}, {"label": "sibling"}]}` (`children` may be left out for a leaf). The second line has the labels of the starting node and the target node.

## Output

Print the labels on the path from the starting node to the target, both included, separated by spaces. Print `none` if either node is not in the tree.
