Create nodes in the order given, then reverse the singly linked list by rewiring `next` references. Return the values reached from the new head. Do not sort the values and do not rely on slicing to reverse the input.

While reversing, save `current.next` before assigning `current.next = previous`. The empty input returns an empty list. A correct solution takes O(n) time and O(1) extra pointer space after the nodes have been built.
