Write a function `is_prime(n)` that returns `True` if `n` is a prime number and `False` otherwise. Remember that `1` is not prime.

> [!TIP]
> If `n` has a divisor larger than its square root, it must also have one smaller than it. So you only need to test divisors up to `sqrt(n)`.

The starter code reads `n` and prints `true` or `false`.
