Write a function `same_chars(a, b)` that checks whether two words are built from the **same set of characters**. How many times each character appears doesn't matter, only which characters appear.

For example, `"abcd"` and `"dddddddabc"` both use exactly `a`, `b`, `c` and `d`, so the answer is `True`. But `"abcd"` and `"dddddddabce"` are different because the second one also contains `e`.

The starter code reads the two words on separate lines.
