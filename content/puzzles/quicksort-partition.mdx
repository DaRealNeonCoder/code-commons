Implement one Lomuto partition on the full list. Use the last value as the pivot, scan the other values, move each value less than or equal to the pivot into the next left position, and finally swap the pivot into its boundary. Print the returned index followed by the mutated list. The empty list prints only `-1`.

At the scan boundary, values before it are no greater than the pivot and values between the boundary and the scan cursor are greater than the pivot. Duplicates must still advance the boundary so the scan always progresses. Partitioning takes O(n) time and O(1) extra space; it is one step of quicksort, not a complete sort.
