Write a function `filter_by_substring(words, sub)` that returns only the words that **contain** the string `sub` somewhere inside them. Keep the original order.

For example, filtering `["abc", "bacd", "cde", "array"]` by `"a"` gives `["abc", "bacd", "array"]`.

The starter code reads the words on the first line and the substring on the second. Every test has at least one matching word.
