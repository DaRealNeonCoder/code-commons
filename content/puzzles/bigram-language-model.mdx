Complete `bigram_counts` and `choose_next`. The input contains a temperature-like value, a current token, and one space-separated training sentence. Count every neighboring pair in the sentence.

Sort the possible next tokens by descending count. Break equal-count ties alphabetically. Clamp the temperature to the range `0` through `1`, then choose this rank:

```text
rank = int(temperature × (number_of_choices - 1))
```

Print the token at that rank. A temperature of `0` selects the most frequent continuation; a temperature of `1` selects the least frequent one. If the current token has no next token, print `<END>`.

This is a deterministic bigram baseline. Real language models use token IDs, learned embeddings, and a probability distribution over a much larger vocabulary, but the counting idea is the same. Use only dictionaries and lists here—no tokenizer, plotting library, or third-party package is required.

> [!TIP]
> When processing `words[index]`, the next token is `words[index + 1]`. The final token has no following pair.
