The `div` with the class `gallery` holds three boxes. Turn it into a grid:

- `display: grid` makes it a grid.
- `grid-template-columns: 100px 200px` defines two columns, 100 and 200 pixels wide.
- `row-gap: 8px` leaves 8 pixels between the rows.

The third box has no column of its own, so the grid starts a new row for it. That's how grids handle extra items.

> [!TIP]
> Columns are listed left to right, separated by spaces. Each number is the width of one column.
