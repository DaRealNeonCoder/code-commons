Implement merge sort recursively. Split a list into two smaller lists until each has at most one item, recursively sort both halves, and merge the sorted halves by repeatedly taking the smaller front item.

Return a sorted copy and leave the input list unchanged. The empty and one-item cases are the base cases. Do not call Python's built-in sorting methods: the purpose is to practice divide-and-conquer and the merge invariant. The expected running time is O(n log n) with O(n) extra list space.
