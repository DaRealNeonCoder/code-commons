Given a list of integers, produce a new list where the element at each position is the largest value seen **so far** (from the start up to and including that position).

Write a function `rolling_max(numbers)` that returns that list.

For example, `[1, 2, 3, 2, 3, 4, 2]` becomes `[1, 2, 3, 3, 3, 4, 4]`.

> [!TIP]
> One pass is enough: carry the current maximum along and update it as you go.

The starter code reads one line of integers and prints the result separated by spaces.
