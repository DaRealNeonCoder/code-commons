You are given two strings, `a` and `b`, made only of the characters `0` and `1`, and both with the same length.

Write a function `string_xor(a, b)` that performs a binary XOR on them and returns the result as a string. At each position the result is `1` if the two characters differ, and `0` if they match.

For example, `"010"` XOR `"110"` is `"100"`.

The starter code reads `a` and `b` on separate lines and prints the result.
