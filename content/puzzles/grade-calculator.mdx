Read a score from 0 to 100 and print the matching letter grade:

| Score | Grade |
| --- | --- |
| 90 to 100 | `A` |
| 80 to 89 | `B` |
| 70 to 79 | `C` |
| 60 to 69 | `D` |
| below 60 | `F` |

For an input of `85`, a correct solution prints `B`.
