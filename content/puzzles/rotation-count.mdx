A list of **distinct** integers was originally sorted in ascending order, then rotated: some number of elements were moved from the end to the front. For example, rotating `[2, 3, 6, 12, 15, 18]` right by 2 gives `[15, 18, 2, 3, 6, 12]`.

Write a function `rotation_count(numbers)` that returns how many positions the list was rotated. A list that is still fully sorted has a rotation count of `0`.

> [!TIP]
> The rotation count equals the index of the smallest element. Binary search can find it by comparing the middle element to the last one.

The starter code reads one line of integers.
