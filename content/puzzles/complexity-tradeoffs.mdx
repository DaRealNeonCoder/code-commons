Compare two ways to answer membership questions. For every target, a linear scan checks values from the beginning until it finds the target or reaches the end. An indexed approach builds a set once, so its simple cost model is `len(values) + len(targets)`.

Return three space-separated numbers: how many targets were found, how many value comparisons all linear scans made, and the indexed approach's setup-plus-query cost. Count a target only once even when `values` contains duplicates. Empty input is valid.
