Implement a separate-chaining hash table with a fixed positive bucket count. The deterministic hash is the sum of the key characters' Unicode code points modulo `capacity`.

`set` inserts or updates an integer value and returns `ok`. `get` returns the value or `missing`. `delete` removes a key and returns `ok`, or returns `missing` when it was absent. `stats` returns three space-separated fields: number of stored keys, number of non-empty buckets, and load factor formatted with two decimal places. Colliding keys must remain independent.
