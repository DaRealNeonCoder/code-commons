Write a function `remove_duplicates(numbers)` that removes **every** element that occurs more than once, keeping only the values that appear exactly once. The remaining elements keep their original order.

This differs from the usual "deduplicate" operation: for `[1, 2, 3, 2, 4]`, both `2`s are removed, giving `[1, 3, 4]`.

> [!TIP]
> Count how many times each value appears first, then do a second pass to keep the ones with a count of 1.

The starter code reads one line of integers. All test inputs keep at least one element.
