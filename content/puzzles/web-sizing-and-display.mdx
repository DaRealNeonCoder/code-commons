Use three rules to control size and display:

1. `.card` gets a `width` of `300px`.
2. `.tag` gets `display: inline-block`, so the two tags sit on one line and keep a size.
3. `.hidden` gets `display: none`, which removes the paragraph from the page.

The paragraph still exists in the HTML. The browser just doesn't draw it.

> [!TIP]
> If the tags appear on separate lines, `inline-block` is the value to check. If the paragraph is still visible, check that the selector matches the class.
