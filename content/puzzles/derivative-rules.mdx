Implement `derivative(kind, x)` using these rules:

- `power` represents `x³`, so its derivative is `3x²`;
- `sine` represents `sin(x)`, so its derivative is `cos(x)`;
- `exp` represents `exp(x)`, so its derivative is `exp(x)`.
