In the JavaScript tab:

- Create a variable named `score` with `let`, holding `10`.
- Create a constant named `bonus` with `const`, holding `5`.

The checks read `score`, `bonus`, and `score + bonus`. The last one should be `15`.

> [!TIP]
> Use `const` unless the value needs to change later. Here `score` uses `let` because a game would usually update it. `bonus` never changes, so it's a constant.
