Write a function `largest_prime_factor(n)` that returns the largest **prime** number that divides `n` evenly. Assume `n >= 2`. If `n` is itself prime, the answer is `n`.

For example, `largest_prime_factor(13195)` is `29` (since `13195 = 5 x 7 x 13 x 29`).

> [!TIP]
> Divide out each small factor completely as you find it. By the time you pass the square root of what's left, the remainder is your answer. This also keeps big inputs like `600851475143` fast.

The starter code reads `n` and prints the result.
