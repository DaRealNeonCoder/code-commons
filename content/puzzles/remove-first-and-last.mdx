Write a function `remove_first_and_last(s, ch)` that deletes the **first** and the **last** occurrence of the character `ch` from the string `s`. All other characters stay in place.

If `ch` appears only once, just remove that one. If it doesn't appear at all, return `s` unchanged. For example, removing `"l"` from `"hello"` gives `"heo"`, and removing `"b"` from `"abc"` gives `"ac"`.

The starter code reads the string on the first line and the character on the second. No test produces an empty result.
