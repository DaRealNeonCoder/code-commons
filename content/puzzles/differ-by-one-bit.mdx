Look at two non-negative integers in binary. Write a function `differ_by_one_bit(a, b)` that returns `True` if their binary representations differ in **exactly one** bit position, and `False` otherwise.

For example, `13` is `1101` and `9` is `1001`, which differ only in the third bit from the right, so the answer is `True`. Equal numbers differ in zero positions, so the answer is `False`.

> [!TIP]
> XOR (`^`) gives a number with a `1` in every position where the inputs differ. The question becomes: is that result a power of two? A power of two has exactly one `1` bit, and `x & (x - 1)` clears the lowest set bit.

The starter code reads both numbers from one line.
