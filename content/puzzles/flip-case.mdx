Write a function `flip_case(s)` that turns every lowercase letter into uppercase and every uppercase letter into lowercase. Characters that aren't letters stay exactly as they are.

For example, `"Hello"` becomes `"hELLO"`.

The starter code reads one line of text and prints the result.
