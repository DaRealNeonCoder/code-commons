Complete the three functions. Each input row contains the true label, the model’s predicted label, and one feature value. The feature is suspicious if it copies the true label for every row; report that as `leaked`.

Print accuracy, precision, and recall on the first line, each rounded to three decimal places. Print `TN FP FN TP` on the second line, then print either `leaked` or `okay` on the third line. Use `0` for a metric whose denominator is zero.

This is an evaluation exercise, not a training exercise: the predictions are supplied so you can focus on what the errors mean. In a real project, calculate these metrics on a test set that was not used to fit the model, and check that every feature would be available at prediction time.

> [!TIP]
> Count the matrix first. Accuracy uses TN and TP, precision uses TP and FP, and recall uses TP and FN.
