The page has a heading with the id `title` and a paragraph with the class `message`. In the JavaScript tab:

1. Use `document.querySelector` to find the `#title` heading, and set its `textContent` to `New title`.
2. Find the `.message` paragraph, and set its `innerHTML` to `<strong>Done!</strong>`, so the word appears in bold.

The checks read the heading, the paragraph's text, and look for the `strong` element inside the paragraph.

> [!WARNING]
> Use `textContent` for plain text and `innerHTML` only when you're writing markup you control. Never put text from a visitor into `innerHTML`.
