Pick some elements from a list of positive integers, keeping their original order, so that each chosen value is **strictly larger** than the one before it. Add them up.

Write a function `max_sum_increasing(numbers)` that returns the largest total you can get this way. For `[1, 101, 2, 3, 100, 4, 5]` the answer is `106`, from `1 + 2 + 3 + 100`.

> [!TIP]
> Let `best[i]` be the best sum of an increasing subsequence that **ends** at position `i`. To compute it, look at every earlier `j` with a smaller value and take the largest `best[j]`, then add `numbers[i]`. The final answer is the maximum of all `best[i]`.

The starter code reads one line of positive integers.
