      const doubled = prices.map((price) => price * 2);
      const expensive = prices.filter((price) => price > 6);
      const total = prices.reduce((sum, price) => sum + price, 0);

The starter defines `prices`. Create three new constants with array methods:

1. `doubled` with `map`, which doubles each price.
2. `expensive` with `filter`, which keeps the prices greater than 6.
3. `total` with `reduce`, which adds all the prices together, starting from `0`.

The checks read all three. Their values should be `[8, 20, 14, 50]`, `[10, 7, 25]`, and `46`.

> [!TIP]
> `reduce` needs the starting value `0` at the end. Its function receives the running sum first, then the current price.
