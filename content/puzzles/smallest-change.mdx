A list is a **palindrome** if it reads the same forwards and backwards. In one change you can replace any single element with any other number.

Write a function `smallest_change(numbers)` that returns the minimum number of changes needed to turn the list into a palindrome. For example, `[1, 2, 3, 4, 3, 2, 2]` needs just 1 change (make the last element a `1`).

> [!TIP]
> Compare the first element with the last, the second with the second-to-last, and so on. Each mismatched pair costs exactly one change.

The starter code reads one line of integers and prints the count.
