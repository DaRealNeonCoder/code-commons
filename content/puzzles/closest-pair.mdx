Given a list of at least two integers, find the two numbers that are **closest to each other** and return them in order, smaller first.

Write a function `closest_pair(numbers)` that returns that pair. For example, `[1, 2, 3, 4, 5, 2]` gives `(2, 2)` because the two `2`s are zero apart. A value that appears twice counts as two separate elements.

> [!TIP]
> After sorting, the closest pair must be neighbours. That turns an all-pairs search into a single pass.

The starter code reads one line of integers and prints the pair separated by a space. Every test has a single closest pair.
