Read an integer `n` and print its multiplication table from 1 to 10, one line per row, in this format:

```
3 x 1 = 3
3 x 2 = 6
...
3 x 10 = 30
```

The example above is the start of the output for the input `3`. Your program should print exactly 10 lines.
