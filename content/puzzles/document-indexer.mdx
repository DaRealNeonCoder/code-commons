Implement `normalize` using lowercase text and a simple punctuation-free word split. `build_index` should add each document ID once per word, then sort each ID list. `search` should normalize the query and return IDs that appear for every query word, sorted for deterministic output.

This puzzle deliberately focuses on pure functions. In the full project, keep filesystem traversal, SQLite persistence, CLI parsing, logging, tests, and concurrency in separate modules around these functions.
