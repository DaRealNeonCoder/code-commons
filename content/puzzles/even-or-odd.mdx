The starter code reads an integer `n`. Print `True` if it is even and `False` if it is odd.

For an input of `4`, a correct solution prints `True`. For `7`, it prints `False`.

> [!TIP]
> A number is even when dividing it by 2 leaves a remainder of `0`. A comparison like `==` gives you a `True` or `False` you can print directly.
