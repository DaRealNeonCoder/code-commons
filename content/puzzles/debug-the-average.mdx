Return `0.0` when `values` is empty. Otherwise return `sum(values) / len(values)`. The empty case is the bug boundary: calling `len(values)` is safe, but dividing by zero is not.

The first input word is setup supplied by the puzzle. When it is `values`, the next line contains the numbers; when it is `empty`, there is no second line.
