You are given several groups of balanced parentheses, separated by spaces. For each group, find the **deepest level of nesting**.

For example, `(()())` reaches a depth of 2, while `((()))` reaches 3 and `()` only 1.

Write a function `nesting_depths(groups)` that takes the list of groups and returns a list with one depth per group.

> [!TIP]
> Walk through each group keeping a counter: add one for `(` and subtract one for `)`. The depth is the highest the counter ever gets.

The starter code reads one line and splits it into groups. For the input `(()()) ((())) () ((())()())`, a correct solution prints `2 3 1 3`.
