The starter code reads a temperature in Celsius as a float. Convert it to Fahrenheit using `F = C * 9 / 5 + 32`, round the result to 1 decimal place, and print it.

For an input of `100`, a correct solution prints `212.0`. For `37`, it prints `98.6`.

> [!TIP]
> `round(number, 1)` rounds to one decimal place.
