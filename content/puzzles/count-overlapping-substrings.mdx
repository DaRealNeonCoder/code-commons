Write a function `how_many_times(s, sub)` that counts how many times the non-empty string `sub` appears in `s`. **Overlapping** occurrences count separately.

For example, `"aaaa"` contains `"aa"` three times (at positions 0, 1 and 2).

> [!TIP]
> Python's built-in `str.count` skips overlaps, so you'll need to check each starting position yourself.

The starter code reads `s` on the first line and `sub` on the second.
