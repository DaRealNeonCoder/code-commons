Complete `objective` and `choose_model`. The first input value is the regularization strength `alpha`. Each following row describes one already-evaluated candidate: its name, hidden-unit count, learning rate, epoch count, training loss, and validation loss.

Use this score:

```text
validation_loss + alpha × hidden_units
```

Choose the smallest score. If two scores tie, choose the alphabetically first name so the answer is deterministic. The learning rate, epochs, and training loss are included to make the hyperparameter comparison visible; the supplied validation loss already reflects those choices.

This is a tiny stand-in for comparing `MLPClassifier` configurations. It uses a validation result and a complexity penalty rather than importing scikit-learn, plotting a graph, or using random training.

> [!TIP]
> A model with the lowest training loss is not automatically the best model. The validation loss estimates how well a choice works on examples it did not train on.
