For an undirected graph, build an adjacency list, visit neighbors in ascending order, and return four results: BFS order from `start`, DFS preorder from `start`, the number of connected components, and the unweighted shortest distance from `start` to `target` (or `-1` when unreachable). Print the results in the format shown by the starter code.

Mark vertices visited when they are discovered. BFS's queue invariant makes the first discovered distance shortest; DFS needs only a visited set to avoid cycles. To count components, start another traversal from every vertex not reached yet. The expected time is O(V + E) and the adjacency list uses O(V + E) space. Isolated vertices count as components.
