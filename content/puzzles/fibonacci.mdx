Write a function `fibonacci(n)` that returns the nth number in the Fibonacci sequence (0-indexed, with `fibonacci(0) == 0` and `fibonacci(1) == 1`). Every number after that is the sum of the two before it: 0, 1, 1, 2, 3, 5, 8, ...

> [!TIP]
> You can solve this recursively, but an iterative loop will be faster for large `n`.
