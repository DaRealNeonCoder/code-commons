Write a function `count_distinct_characters(s)` that returns how many **distinct** characters a string contains, ignoring letter case. `"A"` and `"a"` count as the same character.

For example, `"xyzXYZ"` has 3 distinct characters, and `"Jerry"` has 4 (`j`, `e`, `r`, `y`).

> [!TIP]
> A set only keeps one copy of each value, which makes it a natural fit here.

The starter code reads one line of text (spaces count as characters too) and prints the answer.
