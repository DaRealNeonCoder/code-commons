In the JavaScript tab:

1. Create a constant named `message` that holds the text `Hello, JavaScript!`.
2. Use `document.querySelector("h1")` to find the heading, and set its `textContent` to `message`.

The check reads the heading's text after your script has run.

> [!TIP]
> The script runs as soon as the browser reaches it, at the end of the body. Your heading already exists by then, so `querySelector` can find it.
