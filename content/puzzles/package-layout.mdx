Map module names as follows: `cli` → `entrypoint`, `parsing` and `indexing` → `domain`, `storage` → `infrastructure`, and `tests` → `verification`; use `other` for an unknown name.

For `has_cycle`, treat each edge as `source->destination` and use depth-first search with a set of nodes currently on the search path. A back-edge to a node on that path is a cycle.
