      <!DOCTYPE html>
      <html lang="en">
      <head>
        <meta charset="UTF-8">
        <title>Practice</title>
      </head>
      <body>
        <header>
          <h1>My Blog</h1>
        </header>
        <main>
          <article>
            <h2>First Post</h2>
            <p>Today I started building a website.</p>
          </article>

Use semantic elements instead of generic boxes:

- A `<header>` containing an `<h1>` that says `My Blog`.
- A `<main>` containing an `<article>`. The article holds an `<h2>` that says `First Post`.
- A `<footer>`. Put anything you like inside it.

The checks look for each landmark, and for the text of the two headings.

> [!TIP]
> The `<article>` must be inside the `<main>`, and the `<h2>` must be inside the `<article>`.
