The starter code reads a name from the input. Print a greeting made of the word `Hello` and the name, separated by a comma and a space.

For the input `Ada`, a correct solution prints:

```
Hello, Ada
```

> [!TIP]
> Give `print()` two arguments and use `sep` to control what goes between them.
