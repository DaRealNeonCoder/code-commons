  solution:
    html: |
      <!DOCTYPE html>
      <html lang="en">
      <head>
        <meta charset="UTF-8">
        <title>Practice</title>
      </head>
      <body>
        <p id="intro">I am learning HTML.</p>
      </body>
      </html>
    css: ""
    js: ""
---

Write one paragraph element. Give it the attribute `id="intro"`, and make its text `I am learning HTML.`

The checks also count the paragraphs on the page, so write only one `<p>`.

> [!TIP]
> The attribute goes inside the opening tag: `<p id="intro">`. The text goes between the opening and closing tags.
