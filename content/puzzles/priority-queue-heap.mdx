Implement a list-backed min-heap for the commands `push priority label` and `pop`. A pop returns the label with the smallest priority. When priorities tie, return the label that was pushed first. Popping an empty queue returns `empty`.

Store entries as `(priority, sequence, label)` so Python's tuple comparison gives the required order. After appending, sift up; after removing the root, move the last entry to the root and sift down using the smaller child. The heap invariant is that every parent entry is no greater than its children. Each push and pop should take O(log n) time and use O(1) extra working space beyond the heap.
