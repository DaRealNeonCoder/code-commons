Implement two structures in one command processor. The stack uses LIFO order for `push` and `pop`. The queue uses a fixed-size circular buffer for `enqueue` and `dequeue`; it must not shift all remaining values after a dequeue.

Track queue `head`, `tail`, and `size`. Use modular arithmetic when an index reaches the capacity. A queue at size zero is empty, and a queue at size equal to capacity is full. Capacity is positive in the tests. `clear` empties both structures and resets the queue indices.
