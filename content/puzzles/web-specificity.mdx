    html: |
      <!DOCTYPE html>
      <html lang="en">
      <head>
        <meta charset="UTF-8">
        <title>Practice</title>
      </head>
      <body>
        <p class="note" id="special">Read this.</p>
        <p class="note">Also read this.</p>
      </body>
      </html>
    css: |
      p {
        color: black;
      }

      .note {
        color: green;
      }

      #special {
        color: purple;
      }
    js: ""
---

Write three rules, in this order:

1. `p` sets the color to `black`.
2. `.note` sets the color to `green`.
3. `#special` sets the color to `purple`.

Both paragraphs match the `p` rule and the `.note` rule. Only the first one also matches `#special`. Work out the result before you run it:

- The first paragraph is **purple**, because an id beats a class, which beats an element.
- The second paragraph is **green**, because a class beats an element.

The checks confirm both results.

> [!TIP]
> Rule order matters only when the specificity is equal. Here, each rule is more specific than the one before it, so the order in the file doesn't change the result.
