Write a function `largest_divisor(n)` that returns the largest number **smaller than `n`** that divides `n` evenly. Assume `n >= 2`.

For example, `largest_divisor(15)` is `5`. For a prime number the answer is always `1`.

> [!TIP]
> Counting down from `n - 1` and stopping at the first number that divides `n` works. Can you think of a way to do it with fewer checks?

The starter code reads `n` and prints the result.
