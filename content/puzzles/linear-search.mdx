Search an unsorted list one item at a time.

Write a function `linear_search(numbers, target)` that returns the **zero-based index of the first occurrence** of `target`, or `-1` when the target is not present. The list is not sorted, so you must inspect its elements from left to right. For example, searching for `3` in `[8, 3, 11, 3, 9]` returns `1`, not `3`.

## Input

The first line contains space-separated integers. The second line contains the integer to find. The list may be unsorted and may contain duplicates.

## Output

Print the index of the first matching element, or `-1` if there is no match.

> [!TIP]
> As soon as you find the target, you can return its index. Continuing to scan would risk returning a later duplicate instead.

Linear search takes `O(n)` time in the worst case and does not require the input to be sorted.
