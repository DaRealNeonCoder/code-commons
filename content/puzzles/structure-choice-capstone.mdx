Build a task board from the operations in the starter code. Use a dictionary for active task IDs and a min-heap for priority order. `add task_id priority` inserts or replaces an active task and produces no output. `cancel` returns `cancelled` or `missing`; `next` returns `task_id priority` for the smallest active priority or `empty`; `has` returns `yes` or `no`; and `count` returns the number of active tasks.

Replacing or cancelling a task may leave an old entry in the heap. You can use lazy deletion: when popping, discard an entry unless it still matches the dictionary's current `(priority, sequence)` record. The dictionary invariant is one current record per active ID; the heap contains enough entries to find the next record after stale entries are skipped. Average dictionary operations are O(1), heap insertion and cleanup are O(log n) per entry, and active records use O(n) space.
