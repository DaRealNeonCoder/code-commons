Write a function `make_palindrome(s)` that returns the **shortest** palindrome that begins with the string `s`. You may only add characters to the end.

The idea: find the longest suffix of `s` that is already a palindrome, then append the reverse of whatever comes before that suffix.

For example, `"race"` has the palindromic suffix `"e"`. The part before it is `"rac"`, so we append `"car"` and get `"racecar"`.

The starter code reads a non-empty string and prints the result.
