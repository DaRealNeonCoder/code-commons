Count the rectangles in an ASCII diagram like the one below.

```text
   +--+
  ++  |
+-++--+
|  |  |
+--+--+
```

The above diagram contains these 6 rectangles:

```text

+-----+
|     |
+-----+
```

```text
   +--+
   |  |
   |  |
   |  |
   +--+
```

```text
   +--+
   |  |
   +--+

```

```text

   +--+
   |  |
   +--+
```

```text

+--+
|  |
+--+
```

```text

  ++
  ++

```

You may assume that the input is always a proper rectangle (i.e. the length of every line equals the length of the first line).

## Input

The first line is the number of rows. Each following line is one row of an ASCII diagram made of `+`, `-`, `|` and `.` (a space).

## Output

Print the number of rectangles in the diagram. A rectangle has `+` in all four corners, horizontal sides made only of `-` or `+`, and vertical sides made only of `|` or `+`. In this puzzle spaces are written as `.` on input and output so they survive copy-and-paste; the starter code converts them for you, so your function works with real spaces.
