Read three lines of input: a first name, a last name, and an age. Print a greeting in exactly this format:

```
Hello, Ada Lovelace! Next year you will be 37.
```

That is the output for the inputs `Ada`, `Lovelace` and `36`.

> [!TIP]
> Remember that `input()` returns text. Convert the age before adding 1, and use an f-string to build the final sentence.
