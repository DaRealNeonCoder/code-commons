Implement `numerical_gradient(f, point)`. Return a list with one partial derivative for every coordinate in `point`.

For each coordinate, make a copy of the point, add a tiny `h` to that coordinate, and use:

```text
(f(changed_point) - f(point)) / h
```

The sample function is `f(x, y) = x² + 2y²`. The two printed numbers are the gradient arrow. A positive number means “uphill when this coordinate increases.”

> [!TIP]
> Change one coordinate at a time. If you change both at once, you are measuring a diagonal direction instead of a partial derivative.
