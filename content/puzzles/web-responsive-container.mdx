      <!DOCTYPE html>
      <html lang="en">
      <head>
        <meta charset="UTF-8">
        <meta name="viewport" content="width=device-width, initial-scale=1">
        <title>Practice</title>
      </head>

          <h1>Responsive Page</h1>

    css: |
      .container {
        max-width: 600px;

      @media (max-width: 900px) {

        }
      }

The page should adapt to its width:

1. Give `.container` a `max-width` of `600px`. On wide screens it stops at 600 pixels, and on small screens it shrinks.
2. Add a media query, `@media (max-width: 900px)`, and put a rule inside it for `.container` with a `background-color` of `rgb(230, 240, 255)`.

The viewport `<meta>` line is already there. Leave it in place, because phones need it.

The check runs the page at 800 pixels wide, which falls inside the 900 pixel query, so the background applies.

> [!TIP]
> A media query is a rule with a condition in front of it. The rules inside it only apply when the condition is true.
