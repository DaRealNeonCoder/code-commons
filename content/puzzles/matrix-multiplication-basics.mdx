Implement `matmul(a, b)` with plain Python loops. Do not use NumPy for this puzzle. The matrices are always valid for multiplication: the number of columns in `a` equals the number of rows in `b`.

For each output cell, multiply one row from `a` by one column from `b`, then add the products. Print the resulting matrix one row per line.

> [!TIP]
> If `a` has shape `(rows, middle)` and `b` has shape `(middle, columns)`, the result has shape `(rows, columns)`. That tells you how many times each loop should run.
