Build the supplied general binary tree from its array-shaped description, where `#` means missing and the children of index `i` are at `2*i + 1` and `2*i + 2`. Return and print preorder (node, left, right), inorder (left, node, right), and postorder (left, right, node), separated by `|`.

Do not insert values into a binary search tree: the shape is already given, values may repeat, and an inorder result is not promised to be sorted. Each traversal should visit every existing node exactly once in O(n) time. The empty tree produces three empty sequences.
