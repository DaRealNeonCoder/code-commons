Complete `softmax` and `batch_gradients`. The input images are 64-number lists made by flattening 8 rows of 8 pixels. Each pair in `batch` is `(image, label)`.

`softmax(logits)` should subtract the largest logit, exponentiate the shifted values, and divide each by their total. In `batch_gradients`, calculate probabilities from `scores`, then use `probability - one_hot_label` as the error for each class. Add `error * pixel` to a weight gradient and `error` to its bias gradient.

The provided training loop applies one update per mini-batch. It evaluates on six deterministic test images and prints `pass` when accuracy is at least 90%. Use plain Python only; no NumPy or image library is needed.

> There are three output classes and 64 input pixels. Start the gradient arrays with the same shapes as `weights`: three rows of 64 zeros, plus three bias totals.
