The **Collatz sequence** starts from any positive integer `n`. At each step: if the current number is even, halve it; if it is odd, multiply it by 3 and add 1. It's conjectured that every start eventually reaches `1`.

Write a function `odd_collatz(n)` that returns a sorted list of the **odd** numbers that appear in the sequence, including `n` itself if it's odd and always including the final `1`.

For example, from `5` the sequence is `5, 16, 8, 4, 2, 1`, so the answer is `[1, 5]`.

The starter code reads `n` and prints the list separated by spaces.
