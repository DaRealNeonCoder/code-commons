Return the greatest total reward from a list when neighboring positions cannot both be chosen. You may choose no positions. Print only the best total.

Define `best[i]` as the best total using the first `i` rewards. For the next reward, compare skipping it with taking it plus `best[i - 2]`. The empty prefix is a base case, negative values are allowed, and the input list should not need to be sorted or mutated. A bottom-up solution takes O(n) time; keeping the whole table uses O(n) space, while two previous totals are enough for the final answer.
