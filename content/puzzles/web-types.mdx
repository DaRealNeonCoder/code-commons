Create four constants in the JavaScript tab:

1. `name`, holding the string `"Ada"`.
2. `age`, holding the number `36`.
3. `isStudent`, holding the boolean `false`.
4. `intro`, a template literal that makes the sentence `My name is Ada and I am 36`. Use `${name}` and `${age}` inside it, so the sentence is built from the other two values.

The checks read each value, and also the type of `age`, which should be `"number"`.

> [!TIP]
> Numbers never get quotes, and strings always do. The quotes around `"Ada"` are part of the string. Without them, JavaScript would look for a variable called `Ada`.
