Search for a key in a small B-tree. A B-tree keeps several sorted keys in each node, so one comparison can choose which child to visit.

## Input encoding

The first line contains `L`, the number of levels, including the root and the leaf level. The next `L` lines describe those levels from top to bottom:

- Nodes on one level are separated by semicolons (`;`).
- Keys inside one node are sorted integers separated by commas (`,`).
- Nodes on every level are listed from left to right.

For an internal node with `k` keys, its `k + 1` children are the consecutive nodes on the next level. For example, this describes a three-level B-tree:

```text
3
10,20
2,4;12,15;25,30
0,1;3;5,7;11;13,14;16,18;21,22;27;31,35
```

The input is a valid B-tree encoding: keys are ordered, and every internal node has the required consecutive children. The final line contains the integer to search for.

## Output

Print `found` if the target is one of the keys, or `missing` otherwise. Follow the comparisons at each node to select one child; scanning every key in every level is unnecessary.
