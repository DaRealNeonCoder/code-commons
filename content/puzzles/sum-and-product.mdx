Write a function `sum_and_product(numbers)` that returns a tuple `(sum, product)` for a list of integers.

> [!TIP]
> The product of a single number is just that number, so start your running product at `1`, not `0`.

The starter code reads the numbers from one line and prints the sum and product separated by a space. For the input `1 2 3 4`, a correct solution prints `10 24`.
