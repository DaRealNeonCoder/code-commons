Write a function `get_positive(numbers)` that returns a new list containing only the numbers **strictly greater than zero**, in their original order. Zero is not positive.

For example, `[-1, 2, -4, 5, 6]` becomes `[2, 5, 6]`.

The starter code reads one line of integers. Every test contains at least one positive number.
