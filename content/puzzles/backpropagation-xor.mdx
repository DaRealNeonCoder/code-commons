Implement `backprop(parameters, inputs, target)`. Return a dictionary with the same four groups as the parameters: `W1`, `b1`, `W2`, and `b2`.

The output layer uses binary cross-entropy with sigmoid, so its error starts with `prediction - target`. Send that error backward through `W2`, then multiply each hidden error by `hidden * (1 - hidden)`. A weight gradient is the error at its destination multiplied by the value at its source; a bias gradient is the destination error itself.

The checker compares your result with a centered numerical gradient. After that check, the training loop visits all four XOR examples and subtracts `rate * gradient` from every parameter. The final result must classify all four rows correctly.

> [!TIP]
> `forward` returns `z1`, `hidden`, and the prediction. Reuse those values instead of recalculating them. Work out the output neuron first, then one hidden neuron at a time.
