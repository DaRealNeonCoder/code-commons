Make the **Like** button do something when it's clicked:

1. Find the button with the id `like`.
2. Call `addEventListener` on it with the event name `"click"` and a function.
3. Inside the function, change the text of the paragraph with the id `count` to `1 like`.

The check clicks the button, then reads the paragraph. The click runs your listener, so the text must change to `1 like`.

> [!TIP]
> The second argument to `addEventListener` is a function. Write it as `function () { ... }` or as `() => { ... }`. Either works here.
