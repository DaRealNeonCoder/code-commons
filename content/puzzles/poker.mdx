Pick the best hand(s) from a list of poker hands.

See [Wikipedia][poker-hands] for an overview of poker hands.

[poker-hands]: https://en.wikipedia.org/wiki/List_of_poker_hands

## Input

The first line is the number of hands. Each following line is a five-card hand such as `4S 5H 6C 7D 8S` (ranks `2`-`10`, `J`, `Q`, `K`, `A`; suits `S`, `H`, `D`, `C`).

## Output

Print the winning hand(s), one per line, exactly as given and in input order (several hands print on a tie). Standard poker ranking applies, from high card up to straight flush; an ace can be low in a straight (`A 2 3 4 5`), and suits never break ties.
