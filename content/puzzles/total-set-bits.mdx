A **set bit** is a `1` in a number's binary form. For example, `5` is `101`, so it has two set bits.

Write a function `total_set_bits(n)` that returns the total number of set bits across **all** the numbers from `1` to `n`, inclusive. For `n = 5` the numbers have `1, 1, 2, 1, 2` set bits, so the answer is `7`.

> [!TIP]
> Counting the bits of each number one at a time works. To count a number's bits, repeatedly check the last bit (`x & 1`) and shift right (`x >> 1`) until nothing is left.

The starter code reads `n` and prints the total.
