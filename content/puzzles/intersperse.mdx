Write a function `intersperse(numbers, delimiter)` that inserts the number `delimiter` between every two consecutive elements of `numbers`.

For example, `intersperse([1, 2, 3], 4)` returns `[1, 4, 2, 4, 3]`. Note that there is no delimiter before the first element or after the last one.

The starter code reads the numbers on the first line and the delimiter on the second, then prints the result separated by spaces.
