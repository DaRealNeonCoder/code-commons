Return the feature that best fits each problem:

- `process one item at a time without storing the file` → `generator`
- `add a timestamp to many functions` → `decorator`
- `represent a record with named fields` → `dataclass`
- `run independent CPU-heavy calculations` → `process`
- `share a small cache between calls` → `closure`
- `clean up a resource after use` → `context-manager`

The right answer is not “the most advanced feature.” It is the smallest feature that makes the constraint explicit.
