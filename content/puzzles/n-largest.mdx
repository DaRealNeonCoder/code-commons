Write a function `n_largest(numbers, n)` that returns the `n` largest values in a list, ordered from largest to smallest. If a value appears several times in the list, it can appear several times in the result.

For example, `n_largest([25, 35, 22, 85, 14, 65, 75, 22, 58], 3)` returns `[85, 75, 65]`.

> [!TIP]
> Sorting the whole list and slicing works. If you want to go further, look up a *heap* (priority queue): it can keep just the `n` best values while scanning, which is faster when `n` is small and the list is huge.

The starter code reads the list on the first line and `n` on the second. `n` never exceeds the list length.
