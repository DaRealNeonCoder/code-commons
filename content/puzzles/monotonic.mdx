A list is **monotonic** if its elements are either always going up (or staying equal), or always going down (or staying equal).

Write a function `is_monotonic(numbers)` that returns `True` for a monotonic list and `False` otherwise. For example, `[1, 2, 4, 20]` and `[4, 1, 0, -10]` are monotonic, but `[1, 20, 4, 10]` is not. A list where all values are equal counts as monotonic.

The starter code reads one line of integers and prints `true` or `false`.
