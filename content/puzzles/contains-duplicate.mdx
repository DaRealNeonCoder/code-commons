Write a function `has_duplicate(numbers)` that returns `True` if **any value appears at least twice** in the list, and `False` if every value is unique.

> [!TIP]
> Comparing every pair works but gets slow on big lists. Try keeping a set of values you've already seen: if the next value is in it, you've found a duplicate.

The starter code reads one line of integers and prints `true` or `false`.
