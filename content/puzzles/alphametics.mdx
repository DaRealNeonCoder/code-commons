Given an alphametics puzzle, find the correct solution.

[Alphametics][alphametics] is a puzzle where letters in words are replaced with numbers.

For example `SEND + MORE = MONEY`:

```text
  S E N D
  M O R E +
-----------
M O N E Y
```

Replacing these with valid numbers gives:

```text
  9 5 6 7
  1 0 8 5 +
-----------
1 0 6 5 2
```

This is correct because every letter is replaced by a different number and the words, translated into numbers, then make a valid sum.

Each letter must represent a different digit, and the leading digit of a multi-digit number must not be zero.

[alphametics]: https://en.wikipedia.org/wiki/Alphametics

## Input

A single line containing the puzzle, such as `SEND + MORE == MONEY`.

## Output

If there is a solution, print each letter and its digit as `letter digit`, one per line, sorted by letter. Each letter stands for a different digit, and no number may start with a leading zero. Print `none` if there is no solution.
