Style the `div` with the class `box`:

- Set its `background-color` to `#003366`, a deep blue.
- Set its `color` (the text color) to `white`.

Both values go in one rule, inside curly braces, with a selector of `.box`.

The checks read the colors the browser calculates, so any written form that means the same color passes.

> [!TIP]
> White text on a dark blue background is easy to read. Try swapping in a light background with the same white text, and notice how hard it becomes to read. That's the contrast rule from the lesson.
