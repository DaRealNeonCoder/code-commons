# Content and third-party attributions

CodeCommons contains original application code and educational material, plus
material adapted from other open-source projects. This file records the main
content attributions and points to the source license for each bundled project.

## CodeCommons

Unless a file or directory carries a different notice, the CodeCommons source
code and original educational content are available under the MIT License in
[`LICENSE`](./LICENSE). Contributions retain their existing copyright notices.

## Exercism problem specifications

Many files under [`content/puzzles/`](./content/puzzles/) are adaptations of
Exercism exercises. The individual puzzle files include their exercise name,
source URL, and any original-source attribution in an attribution note at the
end of the file.

- Source project: [Exercism problem specifications](https://github.com/exercism/problem-specifications)
- License: MIT

These adaptations may also identify upstream sources such as Wikipedia, Project
Euler, the Turing School, Chris Pine, or other authors. Those notices and links
are intentionally kept in the corresponding puzzle files and should travel
with the content.

The complete upstream MIT notice is preserved in
[`licenses/EXERCISM-PROBLEM-SPECIFICATIONS-MIT.txt`](./licenses/EXERCISM-PROBLEM-SPECIFICATIONS-MIT.txt).

## HumanEval

Some coding problems and/or test material are adapted from OpenAI's HumanEval
benchmark. Adapted content should be understood as educational adaptations,
not a claim that CodeCommons is the original author of the benchmark material.

- Source project: [OpenAI HumanEval](https://github.com/openai/human-eval)
- License: MIT
- Copyright notice: OpenAI
- Included license notice:
  [`licenses/HUMAN-EVAL-MIT.txt`](./licenses/HUMAN-EVAL-MIT.txt)

Where an individual puzzle is adapted from HumanEval, its content attribution
should remain alongside the puzzle so it is not separated from the material.
